# Prueba de Destacador Amarillo

Este es un texto normal para probar la funcionalidad instalada por J.A.R.V.I.S.

1. Texto resaltado con mark: <mark>Este texto tiene fondo amarillo fluorescente</mark>
2. Texto resaltado con doble igual: ==Este texto tambien esta destacado==
3. Texto resaltado con estilo neon: <mark style="background-color: #fff176; color: #000; padding: 2px 4px; border-radius: 3px;">Este texto tiene estilo redondeado pro</mark>

### Instrucciones de uso:
- Selecciona cualquier palabra o frase en este archivo `.md`.
- Presiona **Ctrl + Shift + H** o **Alt + H**.
- Verás cómo se envuelve al instante en `<mark>...</mark>` con fondo amarillo color destacador.
